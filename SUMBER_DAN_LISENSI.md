## Referensi pengalaman penggunaan

https://www.enterkomputer.com/simulasi

Referensi pola memilih kategori komponen, merangkum harga, dan memeriksa kompatibilitas. Akses langsung halaman dibatasi oleh situs pada saat peninjauan; deskripsi fitur diperiksa melalui hasil indeks publik halaman simulator. Tidak ada penyalinan kode, data harga, foto produk, logo, atau identitas toko. Rakit Lab tidak terafiliasi dengan Enterkomputer.

## Konsep teknis

- Intel, How to Build a Gaming PC: https://www.intel.com/content/www/us/en/gaming/resources/how-to-build-a-gaming-pc.html
- Intel, How to Choose a Motherboard: https://www.intel.com/content/www/us/en/gaming/resources/how-to-choose-a-motherboard.html
- Intel, How to Choose a Power Supply: https://www.intel.com/content/www/us/en/gaming/resources/power-supply.html
- Intel, How Much RAM / RAM Guide: https://www.intel.com/content/www/us/en/gaming/resources/how-much-ram-gaming.html
- GitHub, Configuring a Publishing Source: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

Referensi tersebut mendukung konsep umum. Semua produk, harga, keluarga CPU generik, batas termal, angka daya, dan ketentuan skenario pada katalog adalah data didaktik yang disusun khusus untuk latihan, bukan kutipan katalog Intel atau toko. Kebijakan pencadangan daya model 30% bukan ketentuan resmi universal dari sumber tersebut.

## Aset

`assets/pc-studio.webp`: dibuat dengan imagegen sebagai ilustrasi AI untuk paket ini. Prompt: opened generic black desktop tower on a cool gray workbench, visible motherboard, CPU cooler, RAM and graphics card, spare CPU/RAM in foreground, subtle cyan studio lighting; no text, logos, UI or manufacturer claims. Gambar bukan dokumentasi produk, klaim ukuran, atau petunjuk posisi pemasangan.

Diagram konseptual, ikon garis sederhana, konten pedagogis, dan kode aplikasi dibuat untuk paket ini. Tidak menggunakan foto dari katalog toko, font eksternal, pustaka JavaScript pihak ketiga, atau layanan analitik. Font mengikuti font sistem pengguna.

## Penggunaan

Paket disiapkan agar dapat digunakan, disesuaikan, dan dihosting untuk kegiatan perkuliahan. Simpan atribusi sumber dan label data simulasi saat mengadaptasi. Nama standar seperti AM4, AM5, DDR4, DDR5, SATA, PCIe, dan NVMe digunakan secara deskriptif, tanpa menyiratkan afiliasi atau sertifikasi.
